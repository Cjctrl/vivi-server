**PyQt** is a [Python](Python_\(programming_language\) "Python \(programming language\)") [binding](Language_binding "Language binding") of the [cross-platform](Cross-platform "Cross-platform") [GUI](GUI "GUI") toolkit [Qt](Qt_\(toolkit\) "Qt \(toolkit\)"), implemented as a Python [plug-in](Plug-in_\(computing\) "Plug-in \(computing\)"). PyQt is [free software](Free_software "Free software") developed by the British firm Riverbank Computing. It is available under similar terms to Qt versions older than 4.5; this means a variety of licenses including [GNU General Public License](GNU_General_Public_License "GNU General Public License") (GPL) and commercial license, but not the [GNU Lesser General Public License](GNU_Lesser_General_Public_License "GNU Lesser General Public License") (LGPL). PyQt supports [Microsoft Windows](Microsoft_Windows "Microsoft Windows") as well as various kinds of [UNIX](Unix "Unix"), including [Linux](Linux "Linux") and [macOS](MacOS "MacOS"). 

PyQt implements around 440 classes and over 6,000 functions and methods including: 

  * a substantial set of [GUI widgets](GUI_widget "GUI widget")
  * [classes](Class_\(computer_science\) "Class \(computer science\)") for accessing [SQL](SQL "SQL") [databases](Database "Database") ([ODBC](ODBC "ODBC"), [MySQL](MySQL "MySQL"), [PostgreSQL](PostgreSQL "PostgreSQL"), [Oracle](Oracle_database "Oracle database"), [SQLite](SQLite "SQLite"))
  * QScintilla, [Scintilla](Scintilla_\(editing_component\) "Scintilla \(editing component\)")-based rich text editor widget
  * data aware widgets that are automatically populated from a database
  * an [XML](XML "XML") [parser](Parsing "Parsing")
  * [SVG](Scalable_Vector_Graphics "Scalable Vector Graphics") support
  * classes for embedding [ActiveX](ActiveX "ActiveX") controls on Windows (only in commercial version)



To automatically generate these bindings, Phil Thompson developed the tool [SIP](SIP_\(software\) "SIP \(software\)"), which is also used in other projects.
