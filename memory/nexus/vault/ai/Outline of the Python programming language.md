# Outline of the Python programming language

The following [outline](Outline_\(list\) "Outline \(list\)") is provided as an overview of and topical guide to Python: 

**[Python](Python_\(programming_language\) "Python \(programming language\)")** is a [general-purpose](General-purpose_programming_language "General-purpose programming language"), [interpreted](Interpreted_language "Interpreted language"), [object-oriented](Object-oriented_programming_language "Object-oriented programming language"), [multi-paradigm](Functional_programming "Functional programming"), and [dynamically typed](Dynamically_typed_programming_language "Dynamically typed programming language") [programming language](Programming_language "Programming language") known for its emphasis on code readability 

and broad standard library. Python was created by [Guido van Rossum](Guido_van_Rossum "Guido van Rossum") and first released in 1991. It emphasizes code readability and developer productivity.
