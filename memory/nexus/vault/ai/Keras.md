**Keras** is an [open-source](Open-source_software "Open-source software") [library](Library_\(computing\) "Library \(computing\)") that provides a [Python](Python_\(programming_language\) "Python \(programming language\)") [interface](Interface_\(computing\) "Interface \(computing\)") for [artificial neural networks](Artificial_neural_network "Artificial neural network"). Keras was first independent software, then integrated into the [TensorFlow](TensorFlow "TensorFlow") [library](Library_\(computing\) "Library \(computing\)"), and later added support for more. "Keras 3 is a full rewrite of Keras [and can be used] as a low-level cross-framework language to develop custom components such as layers, models, or metrics that can be used in native workflows in JAX, TensorFlow, or PyTorch — with one codebase." Keras 3 will be the default Keras version for TensorFlow 2.16 onwards, but Keras 2 can still be used.
