**Jinja** is a [web template engine](Template_engine_\(web\) "Template engine \(web\)") for the [Python programming language](Python_\(programming_language\) "Python \(programming language\)"). It was created by [Armin Ronacher](Armin_Ronacher "Armin Ronacher") and is licensed under a [BSD License](BSD_licenses "BSD licenses"). Jinja is similar to the [Django](Django_\(web_framework\) "Django \(web framework\)") template engine, but provides Python-like expressions while ensuring that the templates are evaluated in a [sandbox](Sandbox_\(computer_security\) "Sandbox \(computer security\)"). It is a text-based template language and thus can be used to generate any markup as well as source code. 

The Jinja template engine allows customization of [tags](Tag_\(programming\) "Tag \(programming\)"), [filters](Filter_\(software\) "Filter \(software\)") (for formatting or transforming values), [tests](Conditional_\(computer_programming\) "Conditional \(computer programming\)") (for evaluating conditions), and [globals](Global_variable "Global variable"). Also, unlike the Django template engine, Jinja allows the template designer to call functions with arguments on objects. Jinja is the default template engine for [Flask](Flask_\(web_framework\) "Flask \(web framework\)"), as well as [Home Assistant](Home_Assistant "Home Assistant")'s Automations. It is also used by [Ansible](Ansible_\(software\) "Ansible \(software\)"), [Trac](Trac "Trac"), and [Salt](Salt_\(software\) "Salt \(software\)"). It is also used to make SQL [macros](Macro_\(computer_science\) "Macro \(computer science\)"), for example for use with [dbt](Data_build_tool "Data build tool").
