**CherryPy** is an [object-oriented](Object-oriented_programming "Object-oriented programming") [web application framework](Web_application_framework "Web application framework") using the [Python programming language](Python_\(programming_language\) "Python \(programming language\)"). It is designed for [rapid development](Rapid_application_development "Rapid application development") of [web applications](Web_application "Web application") by [wrapping](Wrapper_pattern "Wrapper pattern") the [HTTP protocol](HyperText_Transfer_Protocol "HyperText Transfer Protocol") but stays at a low level and does not offer much more than what is defined in RFC 7231. 

CherryPy can be a web server itself or one can launch it via any [WSGI](Web_Server_Gateway_Interface "Web Server Gateway Interface") compatible environment. It does not deal with tasks such as templating for output rendering or backend access. The framework is extensible with filters, which are called at defined points in the request/response processing.
