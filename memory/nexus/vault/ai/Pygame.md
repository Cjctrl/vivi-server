**Pygame** is a [cross-platform](Cross-platform "Cross-platform") set of [Python](Python_\(programming_language\) "Python \(programming language\)") modules designed for writing [video games](Video_game "Video game"). It includes [computer graphics](Computer_graphics "Computer graphics") and sound [libraries](Library_\(computing\) "Library \(computing\)") designed to be used with the Python [programming language](Programming_language "Programming language").
