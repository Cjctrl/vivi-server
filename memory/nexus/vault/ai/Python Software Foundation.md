The **Python Software Foundation** (named after the [snake with the same name](Pythonidae "Pythonidae")) (**PSF**) is an American [nonprofit organization](Nonprofit_organization "Nonprofit organization") devoted to the [Python](Python_\(programming_language\) "Python \(programming language\)") [programming language](Programming_language "Programming language"), launched on March 6, 2001. The mission of the foundation is to foster development of the Python community and is responsible for various processes within the Python community, including developing the core Python distribution, managing intellectual rights, [developer conferences](Hackathon "Hackathon") including the [Python Conference](Python_Conference "Python Conference") (PyCon), and raising funds.
