**SQLAlchemy** is an [open-source](Open_source "Open source") [Python](Python_\(programming_language\) "Python \(programming language\)") library that provides an [SQL](SQL "SQL") toolkit (called "SQLAlchemy Core") and an [object–relational mapper](Object%E2%80%93relational_mapping "Object–relational mapping") (ORM) for database interactions. It allows developers to work with databases using Python objects, enabling efficient and flexible database access.
