**IPython** (Interactive Python) is a [command shell](Shell_\(computing\) "Shell \(computing\)") for interactive computing in multiple programming languages, originally developed for the [Python programming language](Python_\(programming_language\) "Python \(programming language\)"), that offers [introspection](Introspection_\(computer_science\) "Introspection \(computer science\)"), [rich media](Rich_media "Rich media"), shell syntax, [tab completion](Tab_completion "Tab completion"), and history. IPython provides the following features: 

  * Interactive shells (terminal and [Qt](Qt_\(software\) "Qt \(software\)")-based).
  * A browser-based [notebook interface](Notebook_interface "Notebook interface") with support for code, text, mathematical expressions, inline plots and other media.
  * Support for interactive data visualization and use of GUI toolkits.
  * Flexible, embeddable interpreters to load into one's own projects.
  * Tools for [parallel computing](Parallel_computing "Parallel computing").



IPython is a NumFOCUS fiscally sponsored project.
