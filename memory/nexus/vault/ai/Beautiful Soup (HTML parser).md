**Beautiful Soup** is a [Python](Python_\(programming_language\) "Python \(programming language\)") package for parsing [HTML](HTML "HTML") and [XML](XML "XML") documents, including those with malformed markup. It creates a [parse tree](Parse_tree "Parse tree") for documents that can be used to extract data from HTML, which is useful for [web scraping](Web_scraping "Web scraping").
