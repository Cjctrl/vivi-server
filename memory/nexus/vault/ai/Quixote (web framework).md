**Quixote** is a [software framework](Software_framework "Software framework") for developing [web applications](Web_application "Web application") in [Python](Python_\(programming_language\) "Python \(programming language\)"). Quixote "is based on a simple, flexible design, making it possible to write applications quickly and to benefit from the wide range of available third-party Python [modules](Modularity_\(programming\) "Modularity \(programming\)")". 

A Quixote application is typically a Python package, a collection of modules grouped into a single [directory tree](Directory_\(file_systems\) "Directory \(file systems\)"). Quixote then maps a [URL](Uniform_Resource_Locator "Uniform Resource Locator") to a [function](Subroutine "Subroutine") or [method](Method_\(computer_science\) "Method \(computer science\)") inside the Python package; the function is then called with the contents of the [HTTP](HTTP "HTTP") request, and the results are returned to the [client](Client_\(computing\) "Client \(computing\)").
