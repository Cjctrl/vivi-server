**TurboGears** is a [Python](Python_\(programming_language\) "Python \(programming language\)") [web application framework](Web_application_framework "Web application framework") consisting of several [WSGI](Web_Server_Gateway_Interface "Web Server Gateway Interface") components such as WebOb, [SQLAlchemy](SQLAlchemy "SQLAlchemy"), [Kajiki](https://pypi.org/project/kajiki/) template language and Repoze. 

TurboGears is designed around the [model–view–controller](Model%E2%80%93view%E2%80%93controller "Model–view–controller") (MVC) architecture, much like [Struts](Apache_Struts "Apache Struts") or [Ruby on Rails](Ruby_on_Rails "Ruby on Rails"), designed to make rapid web application development in Python easier and more maintainable. Since version 2.3 the framework has also been providing a "minimal mode" which enables it to act as a [microframework](Microframework "Microframework") for usage in environments where the whole stack is not required nor wanted.
