**Flask** is a micro [web framework](Web_framework "Web framework") written in [Python](Python_\(programming_language\) "Python \(programming language\)"). It is classified as a [microframework](Microframework "Microframework") because it does not require particular tools or libraries. It has no [database](Database "Database") abstraction layer, form validation, or any other components where pre-existing third-party libraries provide common functions. However, Flask supports extensions that can add application features as if they were implemented in Flask itself. Extensions exist for [object-relational mappers](Object%E2%80%93relational_mapping "Object–relational mapping"), form validation, upload handling, various open authentication technologies and several common framework related tools. 

Applications that use the Flask framework include [Pinterest](Pinterest "Pinterest") and [LinkedIn](LinkedIn "LinkedIn").
