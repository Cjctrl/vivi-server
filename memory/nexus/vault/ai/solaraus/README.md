# Solaraus Project Hub

This is the central hub for the Solaraus project - a local AI assistant that integrates face recognition for secure authentication and provides voice/text-controlled application and web interaction.

## Overview
Solarus combines facial recognition technology with natural language input (both voice and text) to create a secure, personalized AI assistant that can control applications, interact with web services, and automate tasks based on user commands.

- [[Solarus|Main Documentation]] - Primary project overview and face recognition authentication system

- [[Text Command System]] - Processes direct text input and commands
