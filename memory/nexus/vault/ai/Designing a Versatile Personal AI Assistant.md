### 🧑 CJ · 2025-05-25 20:30

**Prompt:**
Create a personal AI assistant that can engage in natural, real-time back-and-forth conversation with the user. The assistant should:
1. **Conversational Abilities**: Respond via voice and/or text in a natural, human-like way. It should remember recent context to maintain coherent conversations.
2. **YouTube Training**: Include a feature where the user can input links to YouTube videos, and the assistant will extract key knowledge from those videos (via transcripts, captions, or audio processing) to learn from them and apply the content in future responses.
3. **User Interface**:
   * A simple, modern interface with a visible **textbox** for user input and assistant replies.
   * A **microphone button** to enable voice input and **speaker output** for responses.
4. **Learning System**: Allow the assistant to store knowledge from the videos in a way that it can reference or be queried later (e.g., "What did I learn from that science video I showed you?").
5. **Customizable Personality**: Let the user adjust the assistant's tone, friendliness, or formality.
6. **Cross-platform**: Works on desktop and mobile browsers.
Optional: Include a feature to summarize videos or quiz the user based on what the assistant learned.
