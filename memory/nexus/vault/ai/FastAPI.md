**FastAPI** is a [web framework](Web_framework "Web framework") for building [HTTP](HTTP "HTTP")-based service [APIs](API "API") in [Python](Python_\(programming_language\) "Python \(programming language\)") 3.8+. It uses Pydantic and type hints to [validate](Data_validation "Data validation"), [serialize](Serialization "Serialization") and deserialize data. FastAPI also automatically generates [OpenAPI](OpenAPI_Specification "OpenAPI Specification") documentation for APIs built with it. It was first released in 2018.
