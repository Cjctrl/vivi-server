**Django** (/ˈdʒæŋɡoʊ/ _JANG -goh_; sometimes stylized as **django**) is a [free and open-source](Free_and_open-source_software "Free and open-source software"), [Python](Python_\(programming_language\) "Python \(programming language\)")-based [web framework](Web_framework "Web framework") that runs on a [web server](Web_server "Web server"). It follows the [model–template–views](Model%E2%80%93view%E2%80%93controller "Model–view–controller") (MTV) [architectural pattern](Architectural_pattern_\(computer_science\) "Architectural pattern \(computer science\)"). It is maintained by the [Django Software Foundation](Django_Software_Foundation "Django Software Foundation") (DSF), an independent organization established in the US as a [501(c)(3)](501\(c\)\(3\) "501\(c\)\(3\)") non-profit. 

Django's primary goal is to ease the creation of complex, [database-driven](Data-driven_programming "Data-driven programming") websites. The framework emphasizes [reusability](Reusability "Reusability") and "pluggability" of components, less code, [low coupling](Loose_coupling "Loose coupling"), rapid development, and the principle of [don't repeat yourself](Don't_repeat_yourself "Don't repeat yourself"). Python is used throughout, even for settings, files, and [data models](Data_model "Data model"). Django also provides an optional administrative [create, read, update and delete](Create%2C_read%2C_update_and_delete "Create, read, update and delete") interface that is generated dynamically through [introspection](Type_introspection "Type introspection") and configured via admin models. 

Some well-known sites that use Django include [Instagram](Instagram "Instagram"), [Mozilla](Mozilla_Foundation "Mozilla Foundation"), [Disqus](Disqus "Disqus"), [Bitbucket](Bitbucket "Bitbucket"), [Nextdoor](Nextdoor "Nextdoor"), and [Clubhouse](Clubhouse_\(app\) "Clubhouse \(app\)").
